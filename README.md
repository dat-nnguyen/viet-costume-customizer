# Việt Phục Remix — Phối Trang Phục Truyền Thống Theo Phong Cách Gen Z

> **Đề thi Audition:** Xây dựng ứng dụng giúp học sinh, sinh viên khám phá và phối trang phục truyền thống Việt Nam (Áo ngũ thân, Áo tấc, Nhật bình, Giao lĩnh, Tứ thân, Bà ba...) theo sự kiện, địa phương hoặc phong cách Gen Z đương đại; tích hợp AI Stylist, ghép mặt chân dung và bảo đảm tính chuẩn mực văn hóa di sản.

---

## 🌟 Tính Năng Nổi Bật

### 1. Phòng Thử Đồ Tương Tác Vector Đa Lớp (Interactive Visual Fitting Studio)
- **Búp bê vector SVG đa tầng thời gian thực:**
  - Tái hiện chuẩn xác từng chi tiết: Cổ áo (Lập lĩnh, Giao lĩnh, Nhật bình viền ngũ sắc, Cổ yếm đào), ống tay (tay chẽn, tay thụng buông rủ dài hơn ngón tay 1 tấc), và cấu trúc vạt hữu (vạt phải đè vạt trái).
  - 5 khuy cài vàng đồng tượng trưng cho **Ngũ Thường** (*Nhân, Nghĩa, Lễ, Trí, Tín*).
  - Phối màu độc lập 3 tầng: Áo ngoài, Áo lót trong, Quần thụng lụa / Chân váy quây / Quần âu suông / Chân váy xếp ly.
- **Tính năng Ghép Mặt Người Dùng (Face Avatar Try-On):**
  - Tải lên ảnh chân dung / selfie từ máy của bạn hoặc chọn nhanh các người mẫu Gen Z Á Đông có sẵn.
  - Bộ công cụ căn chỉnh chuẩn xác: Phóng to / Thu nhỏ (Scale), Dịch chuyển vị trí (X/Y Offset), Xoay góc mặt, Điều chỉnh độ sáng để khuôn mặt khớp hoàn hảo với khăn đóng, nón quai thao, khăn vành dây và cổ áo.

### 2. Bảng Màu Cổ Sắc Việt Nam & Hệ Ngũ Hành Tương Sinh
- Tích hợp 12 sắc độ di sản: *Đỏ Điều (Chu Sa), Chàm Thâm, Vàng Hoàng Yến Cố Đô, Xanh Bích Thủy, Trắng Ngà Tơ Tằm, Tím Hoa Cà Xứ Huế, Nâu Củ Nâu, Hồng Cánh Sen, Đen Huyền Lãnh Mỹ A, Xanh Cổ Vịt, Vàng Mỡ Gà, Xanh Thanh Thiên*.
- Thuật toán tự động phân tích và luận giải thế tương sinh giữa các lớp áo (*Kim sinh Thủy, Thủy sinh Mộc, Mộc sinh Hỏa, Hỏa sinh Thổ, Thổ sinh Kim*) hoặc các phối màu tương phản cá tính.

### 3. Trợ Lý AI Stylist Thông Minh 2 Tầng (Dual-Core AI Stylist)
- **Online Mode (Google Gemini API):** Kết nối trực tiếp mô hình *Gemini 1.5 Flash* khi có API Key để phân tích chuyên sâu ngữ cảnh (dịp lễ, thời tiết, phong cách, tone da).
- **Offline Built-in Expert Engine:** Hệ thống tri thức chuyên gia cổ phục tích hợp sẵn, tự động sinh bản phối hoàn chỉnh (tên outfit đậm chất thơ, gợi ý kiểu tóc & makeup, câu chuyện lịch sử, giải thích lý do phối đồ) **ngay cả khi offline hoặc chưa nhập API Key**. Ứng dụng hoạt động 100% không bao giờ bị gián đoạn.

### 4. Cultural Guardian — Bộ Lọc Thẩm Định Văn Hóa & Cảnh Báo Lệch Chuẩn
- Chấm điểm độ chuẩn mực văn hóa (0 - 100 điểm) theo thời gian thực.
- Đánh giá bối cảnh sử dụng vs. loại y phục (ví dụ: Áo Nhật Bình là đại lễ phục trang trọng, khi đi cà phê dạo phố sẽ gợi ý chuyển sang Áo Ngũ Thân Tay Chẽn).
- Đưa ra lời khuyên văn hóa thân thiện, mang tính giáo dục di sản giúp Gen Z tự tin cách tân mà vẫn giữ gìn giá trị cội nguồn.

### 5. Bách Khoa Cổ Phục Toàn Thư (Heritage Wiki)
- Tra cứu chuyên sâu về **8 dòng cổ phục tiêu biểu**:
  1. *Áo Ngũ Thân Tay Chẽn (Tiền thân áo dài hiện đại)*
  2. *Áo Tấc (Áo ngũ thân tay thụng đại lễ)*
  3. *Áo Nhật Bình (Lễ phục nữ quý tộc hoàng cung triều Nguyễn)*
  4. *Áo Giao Lĩnh (Cổ phục thời Lý - Trần - Hậu Lê)*
  5. *Áo Tứ Thân & Yếm Đào (Dân gian Kinh Bắc, hội Lim)*
  6. *Áo Bà Ba & Khăn Rằn (Nam Bộ phóng khoáng)*
  7. *Áo Đối Khâm (Quý tộc thời Lý - Trần)*
  8. *Áo Dài Tân Thời (Lemur thập niên 1930 & đương đại)*
- Nút *"Mặc Thử Ngay Trong Studio"* chuyển trực tiếp trang phục vào canvas chỉ với 1 click.

### 6. Lookbook Studio, So Sánh Song Song & Chia Sẻ
- **Thẻ Lookbook Tạp Chí (Editorial Lookbook Card):** Xuất bản thẻ thời trang chuyên nghiệp kèm ảnh phối đồ, bảng màu swatches, phụ kiện remix và trích dẫn triết lý nhân sinh.
- **So Sánh Trực Quan (Side-by-side Compare):** Đối chiếu song song giữa *Bản Cổ Điển Nguyên Mẫu* và *Bản Remix Gen Z Đương Đại*.
- **Bộ Sưu Tập Cá Nhân:** Lưu trữ các bản phối yêu thích vào bộ nhớ trình duyệt (LocalStorage), nạp lại vào búp bê hoặc xóa bất kỳ lúc nào.

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ (Local Development)

### Yêu Cầu Hệ Thống:
- Node.js >= 18.0.0
- npm >= 9.0.0

```bash
# 1. Clone repository
git clone https://github.com/dat-nnguyen/viet-costume-customizer.git
cd viet-costume-customizer

# 2. Cài đặt dependencies
npm install

# 3. Khởi động môi trường phát triển (Development server)
npm run dev

# Ứng dụng sẽ chạy tại: http://localhost:5173
```

### Build Kiểm Tra Sản Phẩm (Production Build):
```bash
npm run build
# Bản build tối ưu hóa sẽ được tạo tại thư mục dist/
```

## 🌐 Hướng Dẫn Deploy (Triển Khai Đa Nền Tảng)

Mã nguồn đã được cấu hình sẵn sàng deploy 1-click lên bất kỳ nền tảng nào:

### 1. Deploy lên Vercel (Khuyên Dùng)
Dự án đã có sẵn file [`vercel.json`](file:///Users/datnguyen/Documents/project/viet-costume-customizer/vercel.json) cấu hình SPA routing.
- **Cách 1 (Vercel CLI):**
  ```bash
  npm i -g vercel
  vercel
  ```
- **Cách 2 (Vercel Web Dashboard):**
  1. Kết nối kho GitHub chứa repository này.
  2. Framework Preset: chọn **Vite**.
  3. Build Command: `npm run build`
  4. Output Directory: `dist`
  5. (Tùy chọn) Thêm Environment Variable: `VITE_GEMINI_API_KEY` = your_api_key.
  6. Nhấn **Deploy** -> Hoàn thành!

### 2. Deploy lên Netlify
Dự án đã có sẵn file [`netlify.toml`](file:///Users/datnguyen/Documents/project/viet-costume-customizer/netlify.toml).
- Kết nối GitHub vào Netlify -> Netlify tự động nhận diện file cấu hình và build thư mục `dist` với SPA redirect 200.

### 3. Deploy bằng Docker (Render, Fly.io, Cloud Run, VPS)
Dự án có sẵn [`Dockerfile`](file:///Users/datnguyen/Documents/project/viet-costume-customizer/Dockerfile) (multi-stage build Node 22 -> Nginx Alpine siêu nhẹ dưới 30MB) và [`nginx.conf`](file:///Users/datnguyen/Documents/project/viet-costume-customizer/nginx.conf).

```bash
# Build Docker image
docker build -t viet-costume-customizer .

# Chạy Docker container tại port 8080
docker run -d -p 8080:80 --name viet-costume-app viet-costume-customizer

# Mở trình duyệt tại: http://localhost:8080
```

## 🔑 Cấu Hình Google Gemini API Key (Tùy Chọn)

Ứng dụng **hoàn toàn không bắt buộc API Key** vì đã có sẵn Offline Cultural Expert Engine.
Nếu bạn muốn sử dụng mô hình AI trực tuyến của Google:
1. Lấy API Key miễn phí tại [Google AI Studio](https://aistudio.google.com/app/apikey).
2. Tạo file `.env` từ `.env.example`:
   ```env
   VITE_GEMINI_API_KEY=AIzaSy...
   ```
3. Hoặc nhấn biểu tượng **Chìa khóa (Key)** trực tiếp trên thanh Header của ứng dụng để lưu key trong trình duyệt.
